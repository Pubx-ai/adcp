Retrieve SSP-side delivery metrics for deals including curation-specific metrics (bids, wins, win rate) not available in media buy delivery. This is the curation equivalent of [`get_media_buy_delivery`](/docs/media-buy/task-reference/get_media_buy_delivery).

**Response time**: < 15s | **Schema**: [`get-deal-delivery-request`](/schemas/latest/curation/get-deal-delivery-request.json) / [`get-deal-delivery-response`](/schemas/latest/curation/get-deal-delivery-response.json)

## Quick start

<CodeGroup>
```javascript JavaScript
const delivery = await agent.getDealDelivery({
  deal_ids: ["deal_abc123"],
  include_daily_breakdown: true
});

for (const d of delivery.deal_deliveries) {
  const { impressions, spend, win_rate, avg_cpm } = d.totals;
  console.log(`${d.deal_id}: ${impressions} imps, $${spend} spend, ${(win_rate * 100).toFixed(1)}% win rate, $${avg_cpm} avg CPM`);
}
```

```python Python
delivery = agent.get_deal_delivery(
    deal_ids=["deal_abc123"],
    include_daily_breakdown=True
)
```
</CodeGroup>

## Request fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `deal_ids` | string[] | One of deal_ids/buyer_refs | Deals to report on |
| `buyer_refs` | string[] | One of deal_ids/buyer_refs | Alternative lookup |
| `start_date` | `YYYY-MM-DD` | No | Reporting period start |
| `end_date` | `YYYY-MM-DD` | No | Reporting period end |
| `include_daily_breakdown` | boolean | No | Include daily metrics (default: false) |

## Curation-specific metrics

These metrics are unique to curation deals and not found in media buy delivery:

| Metric | Type | Description |
|--------|------|-------------|
| `bids` | integer | Total bid requests sent to DSPs |
| `wins` | integer | Total auction wins |
| `win_rate` | decimal | Wins / bids (e.g., 0.05 = 5%) |
| `avg_cpm` | number | Average clearing CPM |
