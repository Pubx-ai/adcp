Retrieve deal status and details. Supports filtering by deal IDs, buyer references, status, and platform. This is the curation equivalent of [`get_media_buys`](/docs/media-buy/task-reference/get_media_buys).

**Response time**: < 10s | **Schema**: [`get-deals-request`](/schemas/latest/curation/get-deals-request.json) / [`get-deals-response`](/schemas/latest/curation/get-deals-response.json)

## Quick start

<CodeGroup>
```javascript JavaScript
// Get a specific deal
const result = await agent.getDeals({
  deal_ids: ["deal_abc123"]
});

// List all active deals on Magnite
const active = await agent.getDeals({
  status_filter: "active",
  platform_id: "magnite"
});

for (const deal of active.deals) {
  console.log(`${deal.deal_id}: ${deal.status} on ${deal.platform.platform_name}`);
}
```

```python Python
result = agent.get_deals(
    status_filter=["active", "paused"],
    platform_id="magnite"
)
```
</CodeGroup>

## Request fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `deal_ids` | string[] | No | Specific deal IDs to retrieve |
| `buyer_refs` | string[] | No | Filter by buyer references |
| `status_filter` | string \| string[] | No | Filter by status. Defaults to `["active"]` when no IDs provided |
| `platform_id` | string | No | Filter by SSP platform |
| `account` | AccountRef | No | Filter by account |
| `pagination` | object | No | Cursor-based pagination |

## Response fields

| Field | Type | Always present | Description |
|-------|------|---------------|-------------|
| `deals` | Deal[] | Yes | Matching deals with full state |
| `errors` | Error[] | No | Warnings or errors |
| `pagination` | object | No | Pagination metadata |
