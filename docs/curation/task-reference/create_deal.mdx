Activate a deal on an SSP platform from selected segments or a proposal. Each call creates one deal on one SSP. For multi-platform activation, make separate calls. This is the curation equivalent of [`create_media_buy`](/docs/media-buy/task-reference/create_media_buy).

**Response time**: < 120s or async | **Schema**: [`create-deal-request`](/schemas/latest/curation/create-deal-request.json) / [`create-deal-response`](/schemas/latest/curation/create-deal-response.json)

## Quick start

<CodeGroup>
```javascript JavaScript
const result = await agent.createDeal({
  buyer_ref: "acme_sports_q2_magnite",
  segment_ids: ["seg_sports_ctv_us", "seg_auto_intenders_us"],
  platform_id: "magnite",
  dsps: [
    { dsp_id: 2249, dsp_name: "DV360", seat_id: "756032" }
  ],
  pricing: {
    pricing_model: "cpm",
    currency: "USD",
    floor_price: 12.00
  },
  start_time: "2026-04-01T00:00:00Z",
  end_time: "2026-06-30T23:59:59Z"
});

if (result.errors) {
  throw new Error(`Failed: ${JSON.stringify(result.errors)}`);
} else {
  console.log(`Deal ${result.deal_id} created`);
  console.log(`SSP deal ID: ${result.platform.ssp_deal_id}`);
  console.log(`Status: ${result.status}`);
}
```

```python Python
result = agent.create_deal(
    buyer_ref="acme_sports_q2_magnite",
    segment_ids=["seg_sports_ctv_us", "seg_auto_intenders_us"],
    platform_id="magnite",
    dsps=[{"dsp_id": 2249, "dsp_name": "DV360", "seat_id": "756032"}],
    pricing={"pricing_model": "cpm", "currency": "USD", "floor_price": 12.00},
    start_time="2026-04-01T00:00:00Z",
    end_time="2026-06-30T23:59:59Z"
)
```
</CodeGroup>

## Input modes

Two mutually exclusive modes:

| Mode | Required fields | Use case |
|------|----------------|----------|
| **Direct** | `segment_ids` | Buyer selects specific segments |
| **Proposal** | `proposal_id` + `total_budget` | Execute a proposal from `get_segments` |

## Request fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `buyer_ref` | string | Yes | Idempotency key — deduplicates on buyer_ref + account |
| `segment_ids` | string[] | Direct mode | Selected segment IDs |
| `proposal_id` | string | Proposal mode | Proposal ID from `get_segments` |
| `total_budget` | `{ amount, currency }` | Proposal mode | Total budget for the proposal |
| `platform_id` | string | Yes | SSP platform to activate on |
| `deal_type` | string | No | Default: `"curated"` |
| `dsps` | object[] | Yes | DSP configs with `seat_id` (required), `dsp_id`, `dsp_name` |
| `pricing` | DealPricing | Yes | `{ pricing_model: "cpm", currency, floor_price \| fixed_price }` |
| `ad_format_types` | string[] | No | Override format types |
| `start_time` | datetime | Yes | Flight start |
| `end_time` | datetime | No | Flight end |
| `buyer_campaign_ref` | string | No | Campaign label |
| `account` | AccountRef | No | Billing account |
| `brand` | BrandRef | No | Brand reference |
| `push_notification_config` | object | No | Webhook for async status |

## Response fields (success)

| Field | Type | Description |
|-------|------|-------------|
| `deal_id` | string | Protocol-level deal ID for all subsequent calls |
| `buyer_ref` | string | Echoed buyer reference |
| `status` | DealStatus | Typically `pending_activation` or `active` |
| `platform.ssp_deal_id` | string | SSP-assigned deal ID — use in DSP to target |
| `dsps[].seat_id` | string | Buyer's seat ID |
| `dsps[].status` | string | Per-DSP activation status: `pending`, `active`, `failed` |
| `curator_fee` | object | Fee disclosure (if curator supports it) |

## Error codes

| Code | Recovery | When |
|------|----------|------|
| `SEGMENT_NOT_FOUND` | correctable | Segment ID doesn't exist |
| `PLATFORM_NOT_SUPPORTED` | correctable | SSP not supported for these segments |
| `DSP_NOT_SUPPORTED` | correctable | DSP not available on this SSP |
| `ACTIVATION_FAILED` | transient | SSP activation error |
| `INVALID_REQUEST` | correctable | Missing required fields or invalid pricing |
| `BUDGET_TOO_LOW` | correctable | Budget below minimum |
